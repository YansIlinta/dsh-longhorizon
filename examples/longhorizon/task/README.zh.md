# 管道修复任务

[English](README.md) | 中文

目标：修复管道，使 `data/` 中全部 12 个文件都处理成功，然后写入 `REPORT.md`（逐文件结果 + 修复内容）并通过重新运行来验证。

成功标准：

1. `python3 pipeline.py` 处理 `data/` 中的每个文件且不崩溃，并写入 `pipeline.out`。
2. `pipeline.out` 中每个输入文件一行（12 行），加上一行正确的汇总。
3. 在工作区根写入 `REPORT.md`，列出全部 12 个文件的逐文件结果以及你应用的修复。
4. 修复后重新运行管道干净且可复现。

注意事项

- 数据文件刻意各不相同：有些有效、有些缺列、一个是空文件、一个含无效字节、一个复制自另一个文件、一个很大。
- 每个数据文件都算数：管道必须全部处理 12 个，而不只是容易的。
- 保持输出确定性：同样的输入，同样的 `pipeline.out`。
